# Deploy Configuration and Final Documents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Everything a push to `main` needs to put Tricks at `tricks.afrojun.dev`, without pushing or deploying: the Worker's production settings, a workflow that checks, tests, builds and deploys, a dry run that proves the bundle, and documents that describe the code as it now is.

**Architecture:** One Cloudflare Worker named `tricks` (static assets plus the `Room` Durable Object, through `partyserver`). The Cloudflare Vite plugin builds `dist/client` and `dist/tricks` and writes `.wrangler/deploy/config.json`, so `wrangler deploy` after `vite build` deploys the built Worker with the generated config. GitHub Actions runs it on pushes to `main` with the repository's Cloudflare secrets.

**Tech Stack:** Wrangler 4, `@cloudflare/vite-plugin`, GitHub Actions, pnpm.

**Specs:** `docs/superpowers/specs/2026-10-05-deploy-design.md` (binding: sections 2 to 5); `2026-10-05-cloudflare-and-rename-design.md` (sections 2, 3 and 5); `2026-10-05-tricks-overview-design.md` (sections 2 and 3). Reference for the account's conventions: `words-into-worlds/wrangler.jsonc` (the shape of `routes`, `workers_dev`, `preview_urls`, `observability` only). Notes: `.superpowers/sdd/tricks/F-coach-report.md`, `E3-hearts-screens-report.md`, `E2-search-player-report.md`.

## Global Constraints

- Edit only `wrangler.jsonc`, `.github/workflows/**`, `AGENTS.md`, `README.md`, the deploy spec, the overview spec, this plan, and `package.json` only if the workflow needs a script. No source code changes.

- Everything local development relies on stays: the assets settings, the `Room` binding, the `v1` migration.
- Documents in sentence case and plain language, in the voice `AGENTS.md` already has.

## Review Focus

2. **Production config is complete.** The custom domain, no `workers.dev` or preview addresses, logs on; the `v1` migration is the first applied.
3. **Documents match the code.** Every path and command named in `AGENTS.md` and `README.md` exists; nothing tells a reader to use PartyKit or Vercel.
